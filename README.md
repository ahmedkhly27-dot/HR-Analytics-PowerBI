# HR Analytics Dashboard

## 📊 Project Overview
This project analyzes employee data to uncover insights related to attrition, salary, and workforce distribution using Power BI.

## 🔍 Key Insights
- High attrition in Research & Development department
- Junior employees have the highest turnover rate
- Overtime is strongly correlated with employee attrition

## 🛠 Tools Used
- Power BI
- DAX
- Data Cleaning & Transformation
